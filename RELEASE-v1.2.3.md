# Solace Pro Funscript Player v1.2.3

## Futuristic Bilingual Interface

This release modernizes the Solace Pro Player interface and adds persistent playback/session features while keeping direct BLE control and MPV synchronization.

### New

- Futuristic dark/cyan interface
- Visible FR / EN selector directly in the application header
- Complete French / English interface switching
- Language preference saved between sessions
- Last folder and last video remembered
- Last video restored at startup
- Optional per-video resume position
- Playback position saved periodically and when stopped
- Completed-video resume state cleanup
- Atomic configuration saving
- Robust Funscript loader supporting standard JSON and concatenated JSON blocks
- Improved folder/media workflow
- Redesigned interactive Funscript timeline

### Retained

- Direct Bluetooth Low Energy control for Lovense Solace Pro
- MPV synchronization
- Interactive timeline seeking
- ±10 second seek controls
- Minimum/maximum position controls
- BLE responsiveness adjustment
- Motion amplification
- Folder playlist playback
- Automatic next-video playback
- Optional video + Funscript deletion after completion
