# Solace Pro Funscript Player v1.2.10

## Control Core Update

v1.2.10 introduces a major interface redesign centered around the new **SOLACE // CONTROL CORE** dashboard.

### Highlights

- New Control Core desktop interface
- Live Funscript motion HUD and telemetry
- Live Motion Core position visualization
- Current position, BLE responsiveness, amplification and active-range meters
- Improved playlist selection and playback controls
- Persistent last-folder and last-video restoration
- Optional per-video playback resume
- Collapsible control sections
- Cyber Blue, Matrix Green and Purple Neon themes
- French / English interface
- Interactive Funscript timeline and seek controls
- Direct BLE operation without Intiface

### Run

```bash
python3 Solace-Pro-Funscript-Player-v1.2.10.py
```

### Requirements

Linux, Python 3, Bluetooth Low Energy, MPV and a Lovense Solace Pro. Python dependencies are listed in `requirements.txt`.
